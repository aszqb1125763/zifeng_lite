# Zifeng Lite（子枫技能树 Lite）

> 开源仓库：https://github.com/aszqb1125763/zifeng_lite （MIT）

Minecraft **1.20.1 / Forge** 的简化版技能树：保留原模组的技能树界面与快捷键绑定方式，但只保留五项常驻技能。**没有技能点、没有 HUD、没有转换机、没有光环/木棍/机械/垂钓/枪械等模块。**

## 五项技能（全部免费、进游戏自动解锁）

| 技能 | 效果 | 默认 |
| --- | --- | --- |
| 万载不磨（不毁） | 手持/穿戴物品永不消耗耐久 | 开启 |
| 子枫的苍穹之翼（飞行） | 解锁创造式飞行（双击空格起飞） | 开启 |
| 饱食无忧（不饿） | 饱食度与饱和度永远满值 | 开启 |
| 御空翱翔（飞行速度） | 每级提高飞行速度，可用等级键 0~100 免费调 | 8 级（约 2×），开启 |
| 星瞳夜视（夜视） | 永久夜视，不闪烁 | 开启 |

## 使用

- 按 `N` 打开技能树（只显示「基础」页，五项技能都在这里）。
- 每个技能右侧的 `⚡` 框可绑定**开关键**；飞行速度技能还有第二个**等级键**（+1 / Shift +10 / Ctrl+Shift +100 / Alt 反向）。
- 右键技能行也可以切换开关。
- 界面右下角保留「设置」（界面缩放 / 黑暗模式）与「属性面板」；HUD 调整按钮已删除。
- 所有技能已自动满级，`Ctrl+R` 对五项技能无效（防止误触后要重进世界）。

## 与旧存档

首次进入时会把玩家数据归一化：**删除旧存档里除这五项以外的全部技能**，并把五项设为免费解锁。玩家的开关状态会保留；飞行速度的生效等级也会保留。

## 构建与输出

```bat
gradlew.bat exportLiteJar
```

构建并自动输出到：

`F:\IDEA\简化输出jar`

jar 文件名格式为 **模组名-游戏版本-模组版本**，即：

```text
ZifengLite-1.20.1-1.6.0-lite.jar
```

文件名由 `gradle.properties` 的 `mod_name` + `minecraft_version` + `mod_version` 自动生成（`mod_name` 中的空格会去掉）；改 `mod_name` 会同时改模组显示名和 jar 前缀。

也可以直接双击工程根目录的 `构建并输出简化jar.bat`。

开发测试直接 `gradlew.bat runClient`。

## 说明

- 本工程是从 `zifeng_s_custom_skill_tree_1.20.1` 复刻的 Lite 版，使用独立 modid `zifeng_lite`，**可以和原版 `zifeng_s_custom_skill_tree` 同时安装**。
- 因为 modid 已独立，旧 modid 的存档数据不会自动迁移；Lite 版首次进入会建立自己的玩家数据。
- 为了保持界面不变，源码中仍保留了少数仅供技能树界面复用的旧类；游戏内实际注册/生效的只有五项技能、技能树界面与快捷键。
- 原项目采用 MIT 协议，本 Lite 副本同样遵循。
