# Zifeng Lite（子枫技能树 Lite，1.21.1 NeoForge）

> 开源仓库：https://github.com/aszqb1125763/zifeng_lite （MIT）

Minecraft **1.21.1 / NeoForge 21.1.248** 的简化版技能树：保留原技能树界面与快捷键绑定，只保留五项常驻技能。**没有技能点、没有 HUD、没有转换机、没有光环/木棍/机械/垂钓等模块。**

## 五项技能（全部免费、进游戏自动解锁）

| 技能 | 效果 | 默认 |
| --- | --- | --- |
| 万载不磨（不毁） | 手持/穿戴物品永不消耗耐久 | 开启 |
| 子枫的苍穹之翼（飞行） | 解锁创造式飞行 | 开启 |
| 饱食无忧（不饿） | 饱食度与饱和度永远满值 | 开启 |
| 御空翱翔（飞行速度） | 等级键 0~100 免费调 | 8 级（约 2×），开启 |
| 星瞳夜视（夜视） | 永久夜视，不闪烁 | 开启 |

## 使用

- `N` 打开技能树（只显示「基础」页）。
- 每个技能可绑定开关键；飞行速度额外有等级键。
- 右键技能行也可以切换开关。
- 右下角保留「设置」与「属性面板」，HUD 调整按钮已删除。
- 五项自动满级，`Ctrl+R` 对五项无效。

## 数据

- modid：`zifeng_lite`
- 存档 key：`zifeng_lite_player_data`
- 首次进入会清理五项以外的旧技能，五项自动满级/开启。
- 使用独立 modid，**可以和原版 `zifeng_s_custom_skill_tree` 同时安装**。

## 构建与输出

```bat
gradlew.bat exportLiteJar
```

输出到：

`F:\IDEA\简化输出jar`

jar 文件名：

```text
ZifengLite-1.21.1-1.6.0-lite.jar
```

当前平台说明输出为 `README-1.21.1.md` / `CHANGELOG-1.21.1.md`，不会覆盖其他平台文档。
